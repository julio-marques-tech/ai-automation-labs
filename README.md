# ai-automation-labs

A hands-on learning portfolio in applied AI and automation, built as a
series of guided labs. Each lab produces a real, working project — self-
hosted where applicable — documented end to end: what it does, why it
was built that way, how to run it, and what was learned (real bugs found
and fixed along the way, included).

## Tracks

| # | Track | Status |
|---|---|---|
| 01 | [n8n](01-n8n/) — workflow automation, self-hosted via Docker | Complete |
| 02 | [AI Agents](02-ai-agents/) — agent architecture and orchestration, in code | Complete |
| 03 | RAG (Retrieval-Augmented Generation) | Not started |
| 04 | Skills — building and integrating reusable skills | Not started |
| 05 | Advanced FHIR | Not started |
| 06 | Salesforce | Not started |
| 07 | Slack | Not started |
| 08 | Fine-tuning | Not started |

Each completed track has its own `README.md` (overview and key
takeaways) and `PROGRESS.md` (a log of every lab: what was done,
technical decisions, and problems encountered with how they were
resolved).
