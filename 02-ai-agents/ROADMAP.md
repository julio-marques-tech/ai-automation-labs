# Roadmap — AI Agents Track

Agent architecture and orchestration, built in code (not a no-code tool),
to understand what platforms like n8n's AI Agent node abstract away.

## Execution order

1. **Lab 00 — Fundamentals and setup** (what makes something an "agent" vs.
   a plain LLM call: the reasoning loop, tool use, memory; set up a Python
   environment and confirm how we'll authenticate to Claude)
2. **Lab 01 — Agent from scratch** (a simple agent built directly in code,
   no framework abstractions, to see the mechanics n8n's AI Agent node
   hides)
3. **Lab 02 — Multiple tools and orchestration** (an agent that chooses
   between several tools, with more planning logic)
4. **Lab 03 — Multi-agent coordination** (multiple specialized agents
   working together — a core pattern in production architectures)
5. **Lab 04 — Comparison and documentation** (no-code (n8n) vs. code
   (this track) trade-offs; close out the track's portfolio)
