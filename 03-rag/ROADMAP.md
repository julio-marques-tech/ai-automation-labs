# Roadmap — RAG Track

Retrieval-Augmented Generation, grounded in a realistic AI consulting
scenario: a healthcare interoperability team needs an internal assistant
that answers questions from the official FHIR specification, with
traceable citations.

## Execution order

1. **Lab 00 — Scoping and fundamentals** (a consultant-style requirements
   note for the fictional engagement; RAG concepts: embeddings, vector
   store, chunking, retrieval; Python environment setup)
2. **Lab 01 — Real RAG pipeline** (ingest real, public HL7 FHIR
   specification content, answer questions grounded in it)
3. **Lab 02 — Answer quality and trust** (citations/traceability — which
   source chunk backed each answer; retrieval tuning)
4. **Lab 03 — RAG as an agent tool** (combine with the AI Agents track:
   one agent with both FHIR-doc RAG and Azure DevOps tools)
5. **Lab 04 — Client-facing recommendation memo** (RAG vs. fine-tuning
   trade-offs; a stakeholder-style summary of findings and
   recommendations)
